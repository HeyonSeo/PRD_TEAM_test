# MAN-01 기록지: 처음 쓰는 과장이 60초 안에 등록하는가

> 이 파일을 `records/날짜-man-01-참가자.md`로 복사해서 채웁니다. 진행 방법은 [README](README.md)에 있습니다.

**왜 재나**: PRD는 과장님이 엑셀보다 귀찮다고 느끼면 도구를 쓰지 않는다고 봅니다. "사진, 동·호수, 한 줄로 1분 안에"가 채택의 최소 조건입니다(G-01, FR-REG).

## 기본 정보

| 항목 | 기록 |
|---|---|
| 날짜·장소 | |
| 참가자 | 예: A 과장(○○단지), 50대, 엑셀·카톡 사용 |
| 진행자 | |
| 사용 기기 | 실제 폰(기종: ) / PC 기기 모드 |
| 시안 버전 | `git log --oneline -1` 결과 |

## 진행

1. 시연 데이터를 초기화합니다(폰에서 `index.html` → **시연 데이터 초기화**).
2. 폰에서 `field.html`을 열어 참가자에게 건넵니다.
3. 아래 문장만 말하고 스톱워치를 시작합니다. **그 밖의 설명은 하지 않습니다.**
   > "○○동 ○○호에서 욕실 천장에 물이 샌다는 전화가 왔다고 생각해 주세요. 이 화면으로 사진 두 장 찍어서 접수해 주세요."
4. 참가자가 처음 단지를 고르는 화면이 나옵니다. 단지 고르기는 처음 한 번만 하는 일이라 **시간에 넣지 않습니다.** 등록 화면이 뜬 순간부터 화면 속 타이머가 잽니다.
5. 완료 화면의 "등록 완료 · 00초"를 1회차 시간으로 적습니다.
6. **한 건 더 등록**을 눌러 다른 동·호수, 다른 내용으로 한 번 더 하게 합니다. 두 번째는 익숙해진 뒤의 속도입니다.
7. 마지막으로 아래 "참가자 질문"을 묻습니다.
