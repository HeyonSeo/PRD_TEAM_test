## 준비 (시간에 넣지 않음)

[mockup/README.md](../../mockup/README.md)의 "시연 전 준비"를 따릅니다. 시연 데이터 초기화 → 본부 탭 → 현장 탭 → 등록용 사진 2~3장 준비 순서입니다.

## 진행

1. 청중에게 **아무 설명 없이** "3분만 보여드릴게요"라고 말하고 스톱워치를 시작합니다.
2. [3분 시연 대본](../../mockup/README.md#3분-시연-대본)대로 진행합니다.
3. 끝나면 스톱워치를 멈추고, 질문을 받기 전에 **첫 인상**부터 묻습니다.
