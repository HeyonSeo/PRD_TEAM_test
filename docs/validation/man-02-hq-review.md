## 진행

1. `index.html`에서 **시연 데이터 초기화**를 누릅니다.
2. `hq.html`을 열고 스톱워치를 시작합니다.
3. **본부 화면만 보고** 아래 질문에 답합니다. 엑셀, 메일, 메모장을 열면 그 사실을 적습니다.
4. 다 답하면 스톱워치를 멈춥니다.
