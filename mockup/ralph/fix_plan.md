  - store.js: 접수 목록 읽기·추가·상태 변경, 처음 열 때 시드 데이터 넣기, 시드로 되돌리기

- [x] 2. 현장 등록 흐름 (field.html)
  - 단지는 처음 한 번만 고르면 기억됨(매번 로그인 없음)
  - 등록 화면: 사진 여러 장 한 번에 선택 + 미리보기 → 동 선택 → 호 선택(버튼 목록, 타이핑 없음) → 한 줄 내용 → 등록
  - 입주민 연락처는 동·호수를 고르면 자동으로 채워짐(입력 칸 없음)
  - 입력 칸은 "사진, 동·호수, 한 줄" 세 가지뿐
  - 등록 화면을 연 순간부터 경과 시간을 재서, 완료 화면에 "등록 완료 · 00초" 표시
  - 완료 기준(check.js): 375px에서 사진 2장 + 동·호수 + 한 줄로 등록 성공, 등록된 건이 store에 사진 2장과 함께 저장됨, 가로 스크롤 없음

- [x] 3. 현장 접수 목록과 상태 변경 (field.html)
  - 우리 단지 접수 목록(최근 순), 동·호수로 바로 찾기 → 입주민 전화 왔을 때 바로 답할 수 있게
  - 각 건의 상태를 접수 → 업체 배정 → 보수 완료로 버튼 한 번에 변경, 상태별 경과 일수 표시
  - 완료 기준(check.js): 검색으로 특정 동·호수 건을 찾고 상태를 바꾸면 store에 반영됨

- [x] 4. 본부 대시보드 (hq.html)
  - 상단: 단지 12곳 카드(접수·진행 중·완료 건수, 7일 넘게 멈춘 건은 경고 표시)
  - 하단: 12곳 접수가 한 양식으로 모인 표(단지, 동·호수, 내용, 사진 썸네일, 상태, 접수일, 경과일), 단지·상태로 거르기, 사진 클릭 시 크게 보기
  - 현장에서 새로 등록하면 본부 화면이 새로고침 없이 갱신됨(storage 이벤트), 새 건은 잠깐 강조 표시
  - 상단에 "이번 주 취합: 자동 완료" 같은 한 줄 요약 → 주 1일 걸리던 일이 없어졌다는 걸 보여줌
  - 완료 기준(check.js): 1280px에서 카드 12개, 현장 탭에서 등록한 건이 열려 있던 본부 탭에 새로고침 없이 나타남
